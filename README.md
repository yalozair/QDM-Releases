# Quick Download Manager

مدير تنزيلات لويندوز وأندرويد: تنزيل متعدد الاتصالات، فيديو من يوتيوب والمواقع الأخرى، تورنت، وإضافة للمتصفح.

## التنزيل

حمّل آخر إصدار من صفحة [Releases](https://github.com/yalozair/QDM-Releases/releases):

- ويندوز: `QDM-Setup-x.y.z.exe` (لا يحتاج صلاحيات مدير).
- أندرويد: `arm64-v8a` لمعظم الجوالات، و `armeabi-v7a` للأجهزة القديمة.

هذا المستودع لملفات التثبيت فقط.
